HOW TO SERVE
================================================================================

Option 1: Python 3 (Recommended)
  cd /workspaces/toastmasters-meeting/app
  python3 -m http.server 8000 --directory public
  → Open: http://localhost:8000

Option 2: Python 2
  cd /workspaces/toastmasters-meeting/app/public
  python -m SimpleHTTPServer 8000
  → Open: http://localhost:8000

Option 3: Node.js (if installed)
  cd /workspaces/toastmasters-meeting/app
  npx http-server public
  → Open: http://localhost:8080

Option 4: GitHub Pages (Production)
  Deploy /workspaces/toastmasters-meeting/app/public/ to GitHub Pages

DEPLOYMENT TARGETS
